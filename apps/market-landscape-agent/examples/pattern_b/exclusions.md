# Excluded candidates (2026-09-23)

- **Datadog**: General-purpose APM, not a dedicated LLM observability/evaluation product; only a sidecar LLM module added in 2024 within a broader infrastructure-monitoring stack
- **Dynatrace**: General-purpose APM, not a dedicated LLM observability/evaluation product; Arize (now Dynatrace-owned) is treated separately as the dedicated entity
- **Cisco / Splunk**: General-purpose log analytics/observability platform; Galileo (Cisco-owned) is treated separately as the dedicated vendor
- **Apple**: Acquirer of WhyLabs but not itself a dedicated LLM observability/evaluation vendor — included here as a near-miss parent only
- **Pydantic Logfire**: Near-miss: general-purpose observability tool by the Pydantic team, with AI/LLM evaluation features rather than a dedicated LLM observability/evaluation product
- **MLflow (Databricks)**: General-purpose ML lifecycle platform with LLM evaluation features; not a dedicated LLM observability/evaluation vendor
- **TruEra / TruLens (acquired by Snowflake)**: Near-miss: was a dedicated LLM evaluation open-source product (TruLens) but is no longer sold as a standalone vendor after the Snowflake acquisition; only available as a Snowflake platform component
- **Atlan**: Near-miss: enterprise data catalog/governance product with an AI feature set, not a dedicated LLM observability/evaluation vendor
- **Vellum**: Near-miss: primary product is an AI development/prompt-management platform, with LLM evaluation as a feature rather than a dedicated observability/evaluation product
