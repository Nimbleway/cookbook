# Become an AI power user with the Nimble plugin

A guided session that teaches you to get live web data by talking to your AI assistant.

**This is a lesson, not a tool.** Twenty to thirty minutes, four techniques, no code. You will not
install a library, write a script, or configure anything beyond the plugin itself. If you are
looking for a working application built on Nimble, the other cookbooks are for that.

## Who this is for

Anyone who works in an AI assistant — Claude Cowork, Claude Code, Cursor — and wants their
assistant to read the live web instead of answering from memory. No engineering background needed.

## What you will learn

1. **Ask so it reaches the live web** — and prove that it did
2. **Build on an answer** instead of starting over
3. **Ask once, for many** — one question, twelve subjects, in the shape you asked for
4. **Judge what you got** — the three checks that catch a bad answer

The examples use competitive research on work-management software. The subject matter is
incidental. The four techniques work on whatever you research.

## Start here

Open `ai-setup.md` with your assistant and tell it to walk you through the session.

It handles everything, including checking whether the Nimble plugin is installed and setting it up
if it is not.

## What is in this folder

| File | What it is |
|---|---|
| `ai-setup.md` | The guide. Your assistant reads this and teaches you the session |
| `resources/subjects.csv` | The twelve companies used in the third task |

## Requirements

- An AI assistant with the [Nimble plugin](https://docs.nimbleway.com/plugin-installation) installed. `ai-setup.md` walks you through this if you have not done it.
- A Nimble account. On Claude Cowork you sign in and there is no API key to manage.
