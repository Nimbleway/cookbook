> Record of the headcount checks run on 2026-10-07 after the Web Search Agent run in
> `legal_ai_discovery__pattern_B.json`. The pass/fail calls were made by reading the
> results, so this is a record of the evidence and decisions, not output generated by
> `agent.py`. Illustrative, kept as recorded. Re-run for current findings.

## Why the gate ran

The agent returned 5 companies and 6 near-misses from 22 sources. Every `hq`,
`latest_round`, `sales_role` and `sales_role_url` claim was graded high and cited. All
five `$.companies[i].employee_count` claims came back `confidence: "low"` with
"No usable citation resolved for this value", and each row's text says the headcount is
unverified. Employee count (50 to 500) is a hard constraint, so each of those rows needed
one more check.

On 2026-10-07 the gate covered the low-confidence rows: Sandstone and Billables AI were
searched, and the other three rows reused figures already collected. The current
`agent.py` runs the gate on every row: one search using
`{company} {domain} employees headcount team size`, plus the agent's own claim, then
`headcount_gate()`: only dated figures from the last 12 months count; pass if all of
them fall within 50 to 500, fail if none do or none exist, review if they disagree.

An earlier discovery run on the same day also returned Patlytics. Its gate search
(`Patlytics patlytics.ai employees headcount team size`) found 25 (Tracxn, Dec 2025),
38 (PitchBook), 11-50 and about 60 (Apr 2026): mostly under 50, so it was left out.
Under `headcount_gate()` that mix is `review`.
